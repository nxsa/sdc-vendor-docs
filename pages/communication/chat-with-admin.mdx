---

Store locations can chat with the SameDayCustom Admin. However, the chat can only be initiated by the Admin and not the store location.

When a message is sent to the store from the admin, the following notification cues are sent;

- A toast notification on the left bottom side of the page
- A browser sound notification
- A **New** badge beside the message and also in the message page
