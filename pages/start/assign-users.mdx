---
title: "Assign Users to your Store"
description: ""
---

<Steps>

  <Step title="Open the store edit panel">
    To assign users to a store, click the edit icon on the store as shown below.

    <Frame caption="Store info">
      <img src="/images/assign-users/store-edit-icon.png" />
    </Frame>
  </Step>

  <Step title="Go to the users section">
    Then scroll to the users table and click the **edit** icon.

    <Frame caption="Assign users">
      <img src="/images/assign-users/users-edit-icon.png" />
    </Frame>
  </Step>

  <Step title="Select and save users">
    Select users you want to assign to the store from the dropdown or use the search. Click **Save** when you're done.

    <Frame caption="Select users to assign to store">
      <img src="/images/assign-users/assign-users-modal.png" />
    </Frame>

    <Note>Users that get assigned to a store will only be able to access that store when they're logged in. User roles are the same throughout whichever store they get assigned to.</Note>
  </Step>

</Steps>
