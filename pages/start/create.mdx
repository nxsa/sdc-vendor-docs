After you’ve been approved on the platform, you need to create/setup your store so
you can begin receiving orders that will be assigned to you.

<Steps>
  <Step title="Go to Locations & Settings">
    To create your first store, navigate to **Locations & Settings** by clicking **More** on the sidebar.
    <Frame>
        <img src="/images/createstore/create-1.png" />
    </Frame>
  </Step>

  <Step title="Add a location">
    Click **Add a Location** to create a store.

    <Frame caption="You can add a single store or add multiple store locations at a time">
        <img src="/images/createstore/create-2.png" />
    </Frame>

    <Note>To add multiple locations at a time, simply download the CSV Format, fill in as many stores as you want to add and upload to the system</Note>

  </Step>

  <Step title="Add a single location">
    The following information should be submitted to create a store location.

    <Frame caption="You can add a single store or add multiple store locations at a time">
        <img src="/images/createstore/create-3.png" />
    </Frame>

    **Location Information**
    - Shop name
    - Suite Number (Optional)
    - Street Address (uses google geolocation to get accurate addresses)
    - City
    - State
    - Zip Code
    - Mall name (Optional)
    - Location ID
    - Location Area (Optional)
    - Location Description (Optional)

    **Contact Information**
    - Location phone number
    - Location email address

     <Note>You will need to assign a user to your store to complete the creation</Note>

    After the store has been created you need to finish [setting up the store](/pages/start/setup) so we can assign orders to you.

     <Note>All newly created stores have to be approved by the admin</Note>

  </Step>
</Steps>
